IoT Security Monitoring & Risk Assessment

Project Overview

This cybersecurity portfolio project focuses on IoT security risks involving connected devices, network communications, and critical infrastructure. The project explores security monitoring, log analysis, threat modeling, risk assessment, and incident-response recommendations.

Project Objectives

Examine security risks associated with IoT devices and network communications.

Apply threat-modeling and risk-assessment concepts to identify potential weaknesses.

Explore Splunk for security monitoring, log analysis, and anomaly investigation.

Review Linux system security and network activity.

Examine MQTT security, TLS, and mutual TLS (mTLS).

Develop security recommendations and incident-response documentation.

Tools & Technologies

Splunk: Security monitoring, log analysis, and anomaly investigation.

Linux: System activity, logs, and network-security exploration.

MQTT: IoT messaging protocol and broker security.

TLS/mTLS: Secure communications and certificate-based authentication.

Project Workflow

Understand IoT devices, connections, and assets.

Assess threats, weaknesses, and potential impact.

Monitor system and security activity using Splunk.

Investigate unusual events and gather context.

Document security controls, response steps, and recommendations.

Security Monitoring Example

An illustrative Splunk monitoring scenario involving repeated failed authentication attempts from an IoT device.

Reviewed authentication event patterns.

Identified repeated failed login attempts.

Examined device identity, source, and timing.

Considered escalation through incident-response procedures.

<ins>Note:</ins> The example events are synthetic and do not represent actual PwC or client logs.

Security Recommendations

Implement unique device identities and strong authentication.

Apply least-privilege access.

Protect IoT communications using TLS or mTLS where supported.

Manage and rotate certificates appropriately.

Centralize relevant security logs.

Establish alert logic for unusual authentication and network patterns.

Document triage, containment, escalation, evidence preservation, and recovery procedures.
